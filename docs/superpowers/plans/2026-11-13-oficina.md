# Oficina de estrelas Implementation Plan

**Goal:** Dar utilidade às estrelas de campanha com evolução permanente dos 11 brinquedos.
**Architecture:** Dados de melhorias puros em `src/upgrades.js`; persistência e compra em `save.js`; atributos copiados no início da batalha; UI HTML integrada ao menu atual.
**Tech Stack:** JavaScript ES modules, Canvas 2D, Node test runner, Python builder, Playwright.
**Spec:** `docs/superpowers/specs/2026-11-13-oficina-design.md`.

## Global Constraints

- Salvar em `bvp-save-v1`, preservando versão 1 e progresso legado.
- Manter as 20 fases, brinquedos e custos de colocação existentes.
- Sem dependências de execução externas e sem upgrade obrigatório para vencer.

## Review Focus

- Saves com números inválidos não podem criar saldo infinito nem quebrar o mapa.
- Vitória repetida não pode dar crédito duplicado.
- Gravação bloqueada não pode consumir saldo.
- Melhorias não podem alterar catálogo base ou partida já iniciada.
- Interface móvel, voltar da Oficina e cache offline precisam funcionar.
